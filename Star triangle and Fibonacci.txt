 Star triangle and Fibonacci
for (let i = 1; i <= 4; i++) {
    console.log("*".repeat(i));
}
let a = 0, b = 1;
for (let i = 1; i <= 6; i++) {
    console.log(a);
    let next = a + b;
    a = b;
    b = next;
}
Run: node q24.js
Expected output:
*
**
***
****
0
1
1
2
3
5
Remember: The next Fibonacci number is the sum of the previous two.
